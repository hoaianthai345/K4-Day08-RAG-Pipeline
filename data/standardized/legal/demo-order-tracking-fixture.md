# Order tracking and return support

This order tracking guide helps buyers check a parcel status after payment. The buyer can review the order tracking timeline, delivery partner, expected delivery date, and support options when an update is delayed.

For a return refund policy request, the buyer should retain relevant order evidence and submit the request from the order details page. This local fixture exists only to exercise the lab retrieval pipeline offline.
